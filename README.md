# Telegram Loyalty Platform

Программа лояльности дизайн-агентства: Telegram Mini App с рулеткой бонусов, личным кабинетом клиента, заявками на дизайн и админ-панелью для команды.

- **Клиент** открывает бота → Mini App: крутит рулетку и получает бонус на следующий заказ. Кнопка «Применить бонус» открывает чат с менеджером — сообщение с уникальным номером бонуса уже набрано.
- **Команда**: владелец и тимлид получают в боте уведомление с кнопками «Активировать» и «Вернуть клиенту». В админ-панели (`/admin`) — проверка бонуса по номеру, активация, настройки рулетки, сотрудники и права, статистика, журнал аудита.
- **Три языка** — русский, английский, украинский: бот спрашивает язык при `/start`, на нём работают сообщения бота и мини-приложение.
- **Рассылка** из админки всем, кто нажал `/start`: форматирование, фото, голосовые, кнопки.
- Заказы в приложении не оформляются — их клиент обсуждает с менеджером в Telegram.
- Вся бизнес-логика, включая выбор приза, выполняется на сервере. Данные хранятся в PostgreSQL.

## Стек

Один сервис и одна база: Node.js + TypeScript, Fastify, PostgreSQL, Drizzle ORM (миграции SQL). Веб-клиент — React + Vite, его собранные файлы отдаёт тот же сервер. Тесты — Vitest на настоящем PostgreSQL.

## Быстрый старт (локально)

Нужны Node.js ≥ 22.18 и PostgreSQL ≥ 14.

```bash
npm install
createdb yappibot_dev && createdb yappibot_test
cp .env.example .env        # заполните DATABASE_URL, BOT_TOKEN, SESSION_SECRET
npm run db:migrate          # создать таблицы
npm run db:seed             # стартовый набор призов (один раз)
npm run owner:create -- --telegram-id <ваш Telegram ID> --name "Имя"
npm run dev                 # API на :3000, веб-клиент на :5173
```

Приложение рассчитано на запуск внутри Telegram. Чтобы открыть его в обычном браузере при разработке, получите ссылку с подписанными данными входа (подпись делается токеном бота из `.env`, сервер проверяет её как обычно):

```bash
npm run dev:link -- --telegram-id 123456789 --name "Анна"           # клиент
npm run dev:link -- --telegram-id <ID владельца> --name "Я" --admin  # админ-панель
```

Чтобы бот отвечал на `/start` локально, поставьте `TELEGRAM_UPDATES_MODE=polling`. Кнопка открытия Mini App требует HTTPS-адреса в `APP_URL` (подойдёт любой туннель).

## Команды

| Команда                                                 | Действие                                                        |
| ------------------------------------------------------- | --------------------------------------------------------------- |
| `npm run dev`                                           | Сервер и веб-клиент в режиме разработки                         |
| `npm run build` / `npm start`                           | Сборка и запуск production-версии                               |
| `npm test`                                              | Автотесты (нужна база `yappibot_test`, см. `TEST_DATABASE_URL`) |
| `npm run typecheck` / `npm run lint` / `npm run format` | Проверка типов, линтер, форматирование                          |
| `npm run db:generate`                                   | Создать миграцию после изменения `apps/server/src/db/schema.ts` |
| `npm run db:migrate`                                    | Применить миграции                                              |
| `npm run db:seed`                                       | Стартовые призы (ничего не делает, если призы уже есть)         |
| `npm run owner:create -- --telegram-id … --name …`      | Создать или восстановить владельца                              |
| `npm run bot:setup`                                     | Настроить webhook, кнопку меню и команды бота                   |
| `scripts/backup.sh`, `scripts/restore.sh`               | Резервная копия и восстановление базы                           |

## Обновление боевого сервера

Боевой сервер обновляется сам: всё, что попало в ветку `main` этого репозитория, через пару минут собирается и запускается на сервере (`scripts/deploy.ps1`, подробности — в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)). Перед пушем запускайте `npm test`, `npm run typecheck` и `npm run lint`.

## Что не подключено

- **Google Sheets** — не подключено намеренно (нет доступов и согласованной схемы). Таблицы выгружаются в CSV; точка расширения описана в ARCHITECTURE.md.
- **Банковская интеграция** — оплату подтверждает сотрудник вручную.
